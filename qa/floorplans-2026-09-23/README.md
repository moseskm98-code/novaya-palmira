## Проверки

- `bun run typecheck`, 20 тестов / 148 утверждений, `bun run build`, `bun run build:pages` — успешно.
- `scripts/verify-floorplans.mjs` — локальный Hono и публичный GitHub Pages. На каждом из пяти маршрутов доступен полный каталог, по умолчанию выбран фильтр «Все».
- На компьютере проверены все 21 карточка, все фильтры (21 / 6 / 6 / 6 / 3), стрелки и циклический переход. Для каждого плана проверены заголовок увеличенного изображения, ссылка и фактическое скачивание с побайтовой проверкой SHA-256, уникальное имя файла.
- Для каждого типа проверены выбранное предложение, черновик сообщения и текст в URL WhatsApp: площадь, блок и тип совпадают с карточкой. Внешние ссылки не открывались, сообщения не отправлялись.
- В Chrome с эмуляцией телефона 390×844 выполнены реальные последовательности `Input.dispatchTouchEvent`: свайпы вперёд и назад в «Все» и «Евроформат», обновление выбранного типа, открытие правильного плана и перенос выбора в форму. При смене фильтра каталог начинается с первой карточки. Стрелки скрыты; дробная часть площади имеет размер 52% основной цифры.
- Проверена ширина страницы при 360, 390, 430 и 1440 пикселях; горизонтального переполнения документа нет. Снимки `desktop.png`, `mobile.png`, `mobile-modal.png` просмотрены отдельно.
- Тексты главной сохранены: удалённой подписи нет, заголовок видео «Посмотрите как живёт квартал». Видимые метки «Визуализация» и страница электроснабжения не возвращены.
- `git diff 26c2bd6 -- public/brand public/fonts public/images public/video` пуст: исходные логотипы, шрифты, фотографии и ролики не изменены. Пять маршрутов и прежнее оформление сохранены.
- HTML главной, клиентские JS/CSS и 21 WebP на внешнем адресе побайтово совпали с локальной сборкой: 24 из 24 файлов.

Проверка мобильного поведения выполнена в Chrome с touch-эмуляцией, не на физическом iPhone/Safari. Наличие, цены и этажи PDF не подтверждает; они не добавлялись. Планировки мансард и коммерции в PDF отсутствуют: на соответствующих страницах сохранено пояснение об общем каталоге квартир.
