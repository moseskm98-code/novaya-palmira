# Новая Пальмира — Hono + Bun + React

Реализация первого показанного варианта: `../design-research-2026-09-16/concept-01.png`. Новый бриф от 16.09.2026 — пять самостоятельных рекламных входных страниц. Предыдущий `site-compact` не изменён.

## Запуск

Требуется Bun. `bun install`, `bun run build`, `bun start`. Локальный адрес по умолчанию — http://localhost:3002. `PORT` и `HOST` настраиваются окружением. По умолчанию сервер слушает только 127.0.0.1. `bun dev` пересобирает клиент и запускает сервер с наблюдением; после правок клиентского кода/CSS выполните `bun run build` и обновите браузер.

В данной рабочей папке Bun 1.4.2 установлен локально: `.runtime/node_modules/.pnpm/@oven+bun-darwin-aarch64@1.4.2/node_modules/@oven/bun-darwin-aarch64/bin/bun`. Глобальная установка не изменялась. Зависимости фиксирует `bun.lock`.

## Стек

Hono обрабатывает пять страниц, статику и локальную подготовку обращения. React формирует HTML на сервере и гидратирует интерфейс. Bun — сервер, сборщик клиента, менеджер пакетов и тестовый раннер. Активная реализация не использует Next/Vinext/Vite. Служебные файлы первоначального шаблона Sites оставлены как неиспользуемые; публиковать их Worker вместо Hono-сервера нельзя.

Официальные справочники: [Hono на Bun](https://hono.dev/docs/getting-started/bun), [Bun bundler](https://bun.sh/docs/bundler), [Phosphor icons](https://phosphoricons.com/).

## Страницы

- `/` — главная.
- `/upravlyayushchaya-kompaniya` — УК.
- `/zastroishchik` — Мегаполис Групп.
- `/mansardy` — мансарды.
- `/kommercheskie-pomeshcheniya` — коммерция.

На каждой: собственный первый экран, видео, общая навигация, каталог квартир, контекст квартала, вопросы/условия и обращение. Планы увеличиваются в диалоге, скачиваются; фильтры, переключение вариантов и выбор для обращения работают. Ролики открываются в диалоге с собственными controls; сервер поддерживает Range для перемотки. Поддержаны мобильное меню, нижняя панель действия, клавиатура, focus-visible и reduced motion.

## Содержание и ограничения

Оригинальные логотипы и Montserrat/Arsenal перенесены из локального проекта. Все 21 квартирных плана (типы 1-14 для блоков 3/7 и типы 1-7 для блока 4) извлечены из PDF «Квартирография блок (3_4_7) по отдельности» от 03.09.2026. Одинаковые площади сохранены отдельными позициями, если в документе это разные типы. Контакт и адрес — из текущего `site-compact/app/concepts/_shared/content.ts`; перед публикацией их нужно подтвердить. Просроченное предложение до 31.08.2026 не перенесено.

Точные планы и отдельное видео мансард/коммерческих объектов в просмотренных материалах не найдены. В этих разделах есть запрос специализированной подборки; ниже явно выделен каталог обычных квартир. На мансардах используется обзор квартала, на коммерции — видео инфраструктуры. Это не выдаётся за просмотр конкретного доступного объекта. Для наполнения добавьте подтверждённые записи в `src/data.ts`.

Главный hero сгенерирован встроенным ImageGen по выбранному макету. Его фасадные детали не идентичны фотографии. Промпт: `public/images/hero-home.prompt.txt`. Изображение мансард взято из исходной папки. По просьбе пользователя видимые подписи «Визуализация» удалены с изображений. Остальные фотографии и ролики — исходные материалы проекта. Реальные фото доступны ниже hero.

Форма ничего не отправляет автоматически и не сохраняет имя/телефон. Hono валидирует данные и возвращает черновик сообщения. Посетитель проверяет его и самостоятельно открывает WhatsApp/отправляет сообщение. Никаких утверждений «заявка доставлена» или «запись подтверждена» нет. CRM/почта не подключены. UTM сохраняются в sessionStorage на вкладке, включаются в доступный проверке текст обращения, не отправляются сторонним сервисам автоматически.
